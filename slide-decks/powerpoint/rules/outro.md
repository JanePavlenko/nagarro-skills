# Outro Slide

## Overview
The closing slide of every deck. Always the last slide. Dark background with the Nagarro logo and a closing message.

## Template file
`templates/powerpoint/presentations-skill.pptx`

---

## Variant — Outro (Slide 91)

| Shape name | Content | Position |
|---|---|---|
| `outro-headline` | Closing message | @(various) |

Default closing text: `"Imagine what we can do together!"`

*`nagarro-logo-mint-shadows` is a PICTURE shape — the Nagarro logo is baked in.*

---

## Footer shapes
| Shape name | Content |
|---|---|
| `Digital Design Strategy` | Service line |
| `Project Name` | Project name |
| `Month Year` | Date |
| `2026` | Copyright year |

---

## When to Use
- Always the last slide — no exceptions.
- One slide only.

## Usage Rules
- Do not change the background to light.
- `outro-headline` may be customised to a client-specific closing message, but the default works for most decks.
- Footer must be populated — do not leave "Project Name" as placeholder.
