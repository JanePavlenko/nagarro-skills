# About Nagarro Slides

## Overview
A suite of slides presenting Nagarro's company overview, capabilities, values, and stats. Used in proposals and capability decks to establish credibility. Eight variants serving different contexts and visual approaches.

## Template file
`templates/powerpoint/presentations-skill.pptx`

---

## Variants

### Variant 1 — Services Grid (Slide 31)
Full grid of Nagarro service capability labels. Each text shape is named after the service it labels. Decorative `grid` image baked in.

Key content shapes (named by service label — do not rename):
`Agile software development`, `Test engineering`, `API management`, `Artificial intelligence`, `Big data`, `Business intelligence`, `Cloud enablement & integration`, `DevOps`, `UX/UI design`, and ~20 more.

*This slide is largely static (logo/grid is a background image). Content shapes only need updating if services change.*

## When to Use
| Variant | Best for |
|---|---|
| 1 (Services grid) | Comprehensive capability overview |
| 2 (Values grid) | Cultural fit / employer branding |
| 3 (Impact statement) | Single powerful positioning line |
| 4 (Headline + body) | Mission paragraph with supporting image |
| 5 (Headline only) | Punchy brand statement |
| 6 (Stats) | Proof-of-scale with 6 key metrics |
| 7 (Two columns) | Short positioning, 2-part |
| 8 (Three columns) | 3-part company overview |
| 9 (Three boxes) | Capability-led positioning with 3 themes |
| 10 (Stats bubbles dark) | Visual impact; stats-heavy, dark section |

## Usage Rules
- Use 2–4 About Nagarro slides per deck — not all variants at once.
- Stat values in Variants 6 and 10 must reflect current Nagarro figures.
- Never leave placeholder `Lorem ipsum` or "Nagarro helps them transform…" filler text.
