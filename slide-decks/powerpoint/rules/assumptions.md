# Assumptions Slide

## Overview
A slide listing the key assumptions underpinning the proposal — technical, commercial, or operational. Used in proposals near the end, before the Outro.

## Template file
`templates/powerpoint/presentations-skill.pptx`

---

## Variants

### Variant 1 — Assumptions / Two Items (Slide 80)
Title + two assumption body shapes.

| Shape name | Content | Position |
|---|---|---|
| `assumptions-title` | "Assumptions Taken" | @(88, 773) 1210×83 |
| `assumptions-body-1` | Assumption 1 | Various |
| `assumptions-body-2` | Assumption 2 | Various |

## When to Use
- Include in proposal decks only — placed near the end, before the Outro.
- Use Variant 1 or 3 when there are 2 key assumptions.
- Use Variant 2 when there are 3 key assumptions.
- If more than 3 assumptions exist, use two consecutive slides.
- Omit in capability overview, internal, and kick-off decks.

## Usage Rules
- `assumptions-title` should remain "Assumptions Taken" unless a client uses different terminology.
- Each `assumptions-body-*` shape should contain one clear, complete assumption statement.
- Never leave placeholder assumption text from previous projects.
