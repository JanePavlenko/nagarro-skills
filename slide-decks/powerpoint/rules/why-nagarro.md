# Why Nagarro Slides

## Overview
Slides making the case for choosing Nagarro as a transformation partner. Range from structured 3-phase process slides to direct 2–3 column argument slides.

## Template file
`templates/powerpoint/presentations-skill.pptx`

---

## Variants

### Variant 1 — Why Nagarro / Process Phases (Slide 41)
Three-phase process (Discover / Specify / Build) with per-phase subtitle, AI acceleration points, tools label, and transformation metric. Complex layout — most shapes are named by content.

Key content shapes:
| Shape name | Content |
|---|---|
| `why-title` | Section title (e.g. "New AI Assisted SDLC") |
| `Discover` | Phase 1 label |
| `Specify` | Phase 2 label |
| `Build` | Phase 3 label |
| `phase-title` (×3) | Per-phase "How AI Accelerates X" heading |
| `tools-label` (×3) | "AI TOOLS TO ACCELERATE X" |
| `Transformation` (×3) | "Transformation" label per phase |
| `name_3350 *` (×3) | Transformation metric per phase |

*Phase subtitle/body shapes are named after their content text — do not rename.*

---

### Variant 2 — Why Nagarro / Phase Deep-Dive (Slide 42)
Single phase deep-dive (e.g. "Discover") with traditional challenges vs. AI acceleration columns. Use when expanding one phase in detail.

| Shape name | Content |
|---|---|
| `Discover` | Phase title (top heading) |
| `subtitle` | Phase subtitle |
| `section-title` (×2) | "Traditional Challenges" / "How AI Accelerates Discovery" |
| `tools-label` | "TOP TOOLS THAT WE USE TO ACCELERATE" |
| `Impact and Benefits` | "IMPACT AND BENEFITS" label |

*Bullet/list content shapes are named after their text content.*

## When to Use
| Variant | Best for |
|---|---|
| 1 (Process phases) | Proposals where AI-augmented delivery is the differentiator |
| 2 (Phase deep-dive) | When one phase needs a full slide of elaboration |
| 3 (Three arguments) | Standard "why us" with 3 equal reasons |
| 4 (Two arguments) | When 2 reasons are stronger and more substantiated |

## Usage Rules
- Use only when the audience does not already know Nagarro well (skip in internal decks or existing-client kick-offs).
- `why-title` should be specific: "Why choose Nagarro as your transformation partner?" or similar — not generic.
- Never leave placeholder text in `why-body-*` shapes.
