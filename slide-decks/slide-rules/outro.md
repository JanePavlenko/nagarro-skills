# Outro Slide

## Overview
The closing slide of the deck. All variants are dark by default and include both header and footer.

## Light / Dark Mode
All variants support light and dark mode. Mode can be switched per slide via variables.

## Header & Footer
All variants include header and footer.

## Variants

### Outro - QR Code / Dark
- Title: "Join us at Nagarro", left-aligned, vertically centered
- A large QR code aligned to the right, vertically centered
- Both the title and QR code use `Colors/Mint Green/700`
- Dark background

### Outro - Tagline + Logo / Dark (v2)
- Title: "Let's Co-create Your Next Experience!", centered vertically and horizontally
- Nagarro logo placed next to the title, also centered
- Title and logo are the primary visual elements
- Dark background

### Outro - Tagline + Logo / Dark (v3)
- Same layout as v2
- Title: "Imagine what we can do together!"
- The copy changes but the layout is identical to v2 — choose based on tone

## When to Use
- **Always** — every deck ends with exactly one Outro slide
- Choose variant based on deck type and desired tone:
  - **QR Code**: use for recruitment, employer branding, event, or conference decks where directing the audience to a URL matters
  - **Tagline + Logo (v2 — "Let's Co-create")**: use for client proposals and partnership pitches — collaborative, forward-looking tone
  - **Tagline + Logo (v3 — "Imagine what we can do")**: use for capability overviews, vision decks, or inspiring closes — slightly more aspirational tone

## Usage Rules
- Always use one Outro slide as the very last slide in the deck
- For recruitment or employer branding decks, prefer the QR Code variant
- For client proposals or pitches, prefer the Tagline + Logo variants
- Update the tagline copy to suit the deck's tone — v2 and v3 are interchangeable layouts
