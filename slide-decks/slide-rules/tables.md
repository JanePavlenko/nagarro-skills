# Tables Slides

## Overview
Slides for structured data — milestones, tech stacks, pricing breakdowns, scope matrices, and any tabular information. All variants are light by default.

## Light / Dark Mode
All variants support light and dark mode. Mode can be switched per slide via variables.

## Header & Footer
Information not confirmed for every variant — verify in Figma before use. Most variants include the standard Layout instance, which carries header and footer.

---

## Variants

### Table - Milestones + Dependencies / Light
- Large slide title (no kicker), no header strip above it
- 4 columns: Milestone | What [client] receives | Key dependencies | Approval outcome
- Column headers are rendered in mint/teal accent colour
- Rows are labelled by milestone ID (M1, IM1, M2, M3, M4, Go-Live, etc.); generous row spacing for readability
- Each cell holds a short paragraph of detail
- If the table has more rows than fit on one slide, use the same template on a second slide with the title appended "(cont.)" — there is no separate continuation template
- Use for **project milestone tables** showing deliverables, dependencies, and sign-off criteria per milestone

### Table - Multi-Column Data / Light
- No slide title — the table fills the content area directly
- Column headers have a light grey background fill, dark text, no accent colour
- Rows can be **grouped by category**: the first column shows the category label (e.g. Frontend, Backend) shared across its sub-rows
- Default example shows 4 columns (Category | Sub-category | Description/Tools | Licensing) but **columns and rows can be added or removed freely** — the structure adapts to any data
- Use for **any structured tabular data** with categories and sub-categories: tech stack inventories, scope matrices, deliverable lists, comparison tables, etc.

### Table - Pricing Breakdown / Light
- No slide title — the table fills the content area directly
- 3 columns: Phase | Breakdown | Contract Value (column labels are editable per project)
- Column headers separated by a bold dark navy underline, no fill background
- Supports **sub-rows within a phase** (e.g. Release → Development Cost, Design & Requirements)
- **Total rows** are bold with a light grey highlight; the **grand total row** uses a slightly darker grey background and bold text throughout
- Use for **financial or pricing breakdowns** where phases have line-item costs and one or more subtotal/total rows are needed

## When to Use
- Use whenever the deck has structured data that is best read in rows and columns
- Triggered by brief content such as: "milestones", "deliverables", "pricing", "tech stack", "scope", "dependencies", "breakdown", "comparison"
- Typically placed in the solution/approach or commercials section of a proposal
- Choose variant based on the data type:
  - **Milestones + Dependencies**: use for project milestone tables — deliverables, dependencies, and sign-off criteria per milestone
  - **Multi-Column Data**: use for any structured categorical data — tech inventories, scope matrices, comparison tables
  - **Pricing Breakdown**: use exclusively for financial data with line items, subtotals, and a grand total

## Usage Rules
- Columns and rows are always flexible — add or remove as needed per project
- Do not invent column structures that belong to a different variant (e.g. do not retrofit the Pricing template for milestone data)
- If a table has more rows than fit on one slide, continue on a second slide with "(cont.)" appended to the title
