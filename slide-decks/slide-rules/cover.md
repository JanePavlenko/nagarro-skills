# Cover Slide

## Overview
The opening slide of the deck. Always the first slide. Two layout variants, both dark by default.

## Light / Dark Mode
Both variants support light and dark mode. Mode can be switched per slide via variables — the deck does not need to be uniformly one mode.

## Header & Footer
Neither variant has a header or footer.

## Variants

### Cover - Standard / Dark
- Title is standard size, left-aligned
- Default dark background

### Cover - Large Title, Mint / Dark
- Title is twice the size of the standard variant
- Title fill is `Colors/Mint Green/400`
- Default dark background

## When to Use
- **Always** — every deck starts with exactly one Cover slide
- Use **Cover - Standard** for most decks (proposals, capability overviews, project kick-offs)
- Use **Cover - Large Title, Mint** when the deck title is short and punchy, or when you want a bolder, more energetic opening (e.g. a conference talk, an internal announcement)

## Usage Rules
- Use only one Cover slide per deck — always as the first slide
- The client name or project name goes in the title area
- Switch to light mode if the deck uses a predominantly light theme
