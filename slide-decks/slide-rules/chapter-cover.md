# Chapter Cover Slide

## Overview
Marks the beginning of a new chapter/section in the deck. All variants are dark by default.

## Light / Dark Mode
All variants support light and dark mode. Mode can be switched per slide via variables.

Information not confirmed — verify in Figma before use.

## Variants

### Chapter Cover - Title Left, Number Right / Dark
- Chapter title aligned to the left
- Chapter number aligned to the right
- Standard title size

### Chapter Cover - Large Title Left, Number Right / Dark
- Same layout as the standard variant
- Chapter title is twice the size

### Chapter Cover - Vertically Centered, Number Top / Dark
- Content is vertically centered in the frame
- Chapter number sits on top, chapter title below it

### Chapter Cover - Title Left, Large Navy Number / Dark
- Similar to the standard (title left, number right) layout
- Chapter number is `Colors/Navy/200` and twice the size of the title

### Chapter Cover - Bottom Left / Dark
- Similar to the vertically centered variant
- Content is aligned to the bottom left instead of being centered vertically

## When to Use
- Use at the start of every major section in the deck — one Chapter Cover per chapter
- Triggered whenever the deck outline has a named section that groups multiple slides (e.g. "Our Approach", "The Team", "Commercials")
- Do not use for minor sub-sections within a chapter — reserve for top-level sections only
- Choose variant based on visual tone:
  - **Title Left, Number Right** (standard or large): default choice for most decks
  - **Large Title**: use when the chapter name is short (1–3 words) and deserves visual weight
  - **Vertically Centered, Number Top**: use for a more editorial, magazine-style feel
  - **Title Left, Large Navy Number**: use when the number itself is a strong design element
  - **Bottom Left**: use for a grounded, minimal feel — works well after a high-energy section

## Usage Rules
- Use one Chapter Cover slide at the start of each major section
- The chapter number and chapter title are the primary content — no body copy on this slide
