# About Nagarro Slides

## Overview
Slides presenting Nagarro as a company — their people, values, services, and global presence. 10 slide templates. All are light by default except v8 and v9, which are dark by default. All support light/dark mode switching via variables.

## Components Used

### Content Box
Used in v4. A card component with three swappable elements:
- **Icon** — decorative, swappable (not a photo)
- **Title** — swappable text
- **Description** — swappable body text

## When to Use
- Use to introduce Nagarro as a company — include when the audience does not know Nagarro well, or when the deck needs to establish credibility before the commercial close
- Place toward the end of the deck: after the delivery/approach and Why Nagarro sections, followed by Team and then Outro
- Do not include all 10 variants in one deck — select 2–4 that serve the deck's purpose:
  - **v1 (Headline + Stats Grid)**: default opener for the About section — covers who Nagarro is in one slide
  - **v2 (Headline + 2 Col Body)**: use when a fuller text description is needed alongside the headline
  - **v3 (3 Col Text + Full-Width Image)**: use when a strong visual is available and you want to anchor the section emotionally
  - **v4 (Headline + 3 Content Boxes)**: use to highlight 3 specific capabilities, values, or pillars concisely
  - **v5 (Label + Large Quote)**: use for a bold, single-statement impact slide — works well as a section opener
  - **v6 (Headline + Body Left, Photo Right)**: use when you have a good team photo and want a balanced text-image layout
  - **v7 (Headline Top Left, Photo Collage Right)**: use when multiple team photos are available
  - **v8 (Stats Bubbles, Full-Width Photo)**: use to show Nagarro's scale at a glance — strong for first impressions
  - **v9 (Caring Values)**: use when the audience will respond to culture and values (recruitment, partnership, brand decks)
  - **v10 (Services Icon Grid)**: use when the breadth of Nagarro's services is a key selling point

## Usage Rules
- Use these slides to introduce Nagarro early in the deck, typically after the cover and index
- v8 (Stats Bubbles) is fixed in layout — only update the numbers, do not restructure
- v9 (Caring Values) uses a vector for "caring" — do not attempt to edit it as text
- v3 intentionally has no footer to avoid it overlapping the full-width image
- For v4, source Content Box icons from the Local Components library — icon, title and description are all swappable per instance
- For photo slides (v6, v7), source images from Images - References → People section
