# Why Nagarro Slides

## Overview
Slides making the case for choosing Nagarro as a partner — covering differentiators, AI-assisted delivery methodology, and proof points. 4 slide templates, all light by default. All support light/dark mode switching via variables.

## Header & Footer
- All 4 slides have a header (the Nagarro logo at the top is a variant of the header component)
- All slides have a footer **except** v2 (AI Assisted SDLC, Detail)

---

## Variants

### v1 — Why Nagarro - AI Assisted SDLC, 3 Col / Light
- Title "New AI Assisted SDLC" top left
- Content divided into columns (2 or 3 depending on the project — the number of detail slides, v2, should match the number of columns here)
- Each column contains:
  - Column title + description
  - Divider line
  - "How AI Accelerates [phase]" subtitle + bullet points
  - AI tool logos row
  - Transformation banner (Navy/700 fill, white text, Mint Green/400 label)
- Has header and footer
- Light background by default

### v2 — Why Nagarro - AI Assisted SDLC, Detail / Light
- Detail/expansion view of a single column from v1
- Title (phase name, e.g. "Discover") + subtitle top left
- Below: 2 content boxes side by side — Traditional Challenges (left) / How AI Accelerates (right, with light grey fill)
- Below that: 2 columns — Tools list (logos + names grouped by category) on the left | Impact & Benefits (icon + metric rows) on the right
- Full-width Transformation banner at the bottom (Navy/700 fill, Mint Green/400 label, white body text with key stats)
- Has header, **no footer**
- Light background by default
- Usage: duplicate this slide once per column in v1 — if v1 has 3 columns (Discover, Specify, Build), use 3 instances of this slide, one per phase

### v3 — Why Nagarro - Headline + 2 Col Body / Light
- Left column: large headline (e.g. "Why choose Nagarro as your transformation partner?")
- Middle and right columns: body copy split across 2 columns with bold lead-ins per paragraph
- Has header and footer
- Light background by default

### v4 — Why Nagarro - Headline Top, 3 Col Body / Light
- Large headline spanning full width on top
- Body copy split across 3 equal columns below
- Has header and footer
- Light background by default

## When to Use
- Use when the audience does not already know Nagarro well enough to choose them without a case being made — most common in first-contact proposals and competitive pitches
- Skip when the client has an established relationship with Nagarro and the deck is about the specific project, not the partnership decision
- Typically placed after the delivery/approach sections and before About Nagarro and Our Partners
- Choose variants based on the message structure:
  - **v1 + v2 (AI Assisted SDLC)**: use when the key differentiator is Nagarro's AI-augmented delivery methodology — v1 gives the overview, one v2 per phase provides the detail. Use this pair when the client cares about HOW Nagarro delivers
  - **v3 (Headline + 2 Col Body)**: use for a denser, text-heavy argument — good when the "why Nagarro" case has many nuanced points
  - **v4 (Headline Top, 3 Col Body)**: use when the argument can be structured into 3 clear, equal pillars

## Usage Rules
- v3 and v4 carry the same headline — choose based on how much body copy there is: v3 for denser text (the headline col acts as breathing room), v4 when the copy fits naturally across 3 equal columns
- v1 and v2 work as a pair: always follow v1 with one v2 slide per column — do not use v2 without v1 preceding it in the deck
- The Transformation banner in v1 and v2 uses `Colors/Navy/700` fill with `Colors/Mint Green/400` for the label — do not change these colors
- All slides support dark mode via variable switching — no separate dark frames needed
