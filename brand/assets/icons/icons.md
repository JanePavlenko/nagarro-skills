# Icon Usage Rules

All icons live in `brand/assets/icons/` as 96×96 PNG files.
Use the filename without extension as the icon key.

---

## How to pick an icon

Match the **slide topic or column header** to a group below, then pick the most specific icon that fits. If nothing fits exactly, use the closest semantic match. Never invent an icon name.

## Rules

1. **One icon per column** on three-column slides — never reuse the same icon twice on one slide.
2. **Match semantics, not aesthetics** — pick by meaning, not by which icon looks coolest.
3. **Avoid path icons** (`path-spring`, `path-zigzag`, `tornado`, `waves`, etc.) on content slides — they are decorative and carry no meaning on their own.
4. **Default icons when nothing fits:**
   - Generic capability or service → `stack`
   - Generic value/outcome → `checkmark`
   - Generic people/team → `people`
   - Generic partnership → `handshake`
   - Generic innovation → `sparkle`
5. **Never use industry verticals** (health, automobile, gaming, etc.) unless the slide explicitly targets that industry.
